# ADR 0002: 双减脂模式（532 / 碳循环）数据模型设计

- 状态：Accepted
- 日期：2026-09-04

## 背景

产品提供两种减脂模式：**532 碳水渐降**（自然月周期，固定 50/30/20 占比 + 体重联动调碳）与**碳循环**（7–14 天周期，目标体重驱动的碳水池/脂肪池 + 高中低碳日型）。两模式共用「基准热量 = TDEE − X」。用户可切换模式，切换即终止当期周期。历史数据须永久留存、多版本可追溯。

备选：每模式一张专属宽表 vs 统一档案 + 模式快照分离。

## 决策

1. **档案与快照分离**：`user_body` 保存当前档案（性别 / 年龄 / 身高 / 体重 / 目标体重 / 活动系数 / BMR / TDEE / 缺口 X / cfc），周期数据（每日宏量 / 体重记录 / 调碳日志）独立按模式建模。
2. **切换即重置**：模式切换自动终止当前周期、清空当期进度（碳水池等）、重启全新周期；历史周期数据留档不删。
3. **cfc 持久化**：脂肪系数 cfc（0.8/1.0）保存在用户档案，**不随周期重置**。
4. **数值存储**：营养克数 / 热量按 `DOUBLE` 存储防累计漂移（PRD §5③），展示层四舍五入到整数克；涉及真实金额才用 `DECIMAL`。
5. **多版本追溯**：身体 / 运动数据修改时自动覆盖当前值并留存历史版本。

## 后果

**正向**：两模式互不污染；周期独立核算便于「切换 / 提前结束清空碳池」的强规则落地；档案统一展示基准热量。

**负向 / 权衡**：周期表需带模式标识与周期号；「清空当期进度」须在事务内完成（多表一致性写操作加 `@Transactional`）。
