## 口径冲突裁决规则

两份 PRD 并存时：**最终版 PRD（开发交付版）优先**——其 §0 明确记录了对含食物库版的关键变更（基准热量 = TDEE − X 同时适用两模式、碳循环改图片公式、532 缺口 200/300/400、新增目标体重输入、cfc 可切换 0.8/1.0、日型占比 50%/2、35%/2.2、15%/2）。数据表结构、埋点、异常处理等最终版未覆盖的内容以含食物库版为准。**「业务规则与公式速查」docx（提取件 `doscFile/projectFile/02-业务规则与公式速查.md`）为计算口径最终细化**：缺口档位补 500（200/300/400/500）、碳循环周期 7–14 天、平台期判定近 7 天波动 <0.3kg、经期四阶段上浮（经期 +15g/+60kcal、排卵 +5g/+20kcal、黄体 +10g/+120kcal）——与旧 PRD 冲突时以速查为准。
