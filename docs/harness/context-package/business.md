## 1. 约束解决方案的业务规则

### 1.1 全局核心规则（全功能通用，优先落地）

1. 所有用户数据（个人资料、减脂模式、周期、饮食、体重）**永久云端留存，不自动清空**。
2. 用户切换减脂模式：**自动终止当前周期、清空当期进度、重启全新周期**。
3. 所有健康计算结果内置**免责声明**：仅作生活化减脂参考，非医疗建议。
4. 所有用户输入数值做人体合理区间校验，**后端二次兜底**，拒绝异常数据计算。
5. 用户隐私数据加密存储、禁止明文传输。
6. 游客体验：首次进入默认授予 **3 天完整功能游客体验**（无阉割）；到期需微信授权登录；游客数据临时留存，登录后自动迁移合并；过期未登录临时数据保留 7 天后清空。
7. **减脂缺口基准**：532 与碳循环共用「基准热量 = TDEE − X」，X 用户自选（温 200 / 标 300 / 积 400 / 500，**默认 200**）。

### 1.2 账号与登录

- 微信一键授权登录，无需手机号，`openid` 唯一绑定用户账号；登录状态持久化。
- 游客时效从首次打开小程序计时（自然 3 天）；进入第 4 天 0 点弹出**不可关闭**的强制授权弹窗（仅可授权登录 / 退出小程序）。
- 授权失败重试机制、游客浏览兜底。
- 游客时效 / 权限 / 数据迁移**由后端校验**，前端计时仅展示。

### 1.3 计算口径（9/3 图片公式定稿，开发唯一口径）

- **BMR**（Mifflin-St Jeor）：女 `10W+6.25H−5A−161`；男 `10W+6.25H−5A+5`。
- **TDEE** = BMR × 活动系数（久坐 1.2 / 轻度 1.375 / 中度 1.55 / 高度 1.725）。
- **区间校验**：年龄 12–80、身高 100–250cm、体重 25–200kg、目标体重 25–200kg 且 ≤ 当前体重。
- **碳循环**：每日蛋白 = 当前体重 × 1.5g（固定）；总碳水池 = 目标体重 × 2.5 × cycleDays；总脂肪池 = 目标体重 × cfc × cycleDays（cfc 默认 0.8，可调 1.0，持久化不随周期重置）；日型分配 高/中/低 = 总量 × 50%/2、35%/2.2、15%/2（周期按比例放大：7 天 2/2.2/2，14 天 4/4.4/4）；碳+脂占总量 100% 守恒。
- **532**：固定占比 碳 50% / 蛋白 30% / 脂肪 20%（硬性写死，不守脂肪下限）；自然月周期 4 阶段（适应期 → 经期适配期 +15g 碳/+60kcal → 经后高效期 → 平台突破期）；平台期判定：每周一空腹称重为标准采集点，近 7 天体重记录（≥2 条）最大值 − 最小值 < 0.3kg 即判定 → 碳水 −20g / 总热量 −80kcal；**单次仅降 20g、禁止连续多周递减、恢复下降即停**。
- **经期四阶段**（女性开启经期管理后）：经期 +15g 碳 / +60kcal（补铁温补）；排卵期 +5g / +20kcal；黄体期 +10g / +120kcal（控盐防暴食）；卵泡期基线不变；蛋白脂肪均不上浮；男性 / 未开启不叠加。
- 运动日优先占高碳位、其次中碳位；不标记默认轮播 `高·中·低·低·中·高·低`。
- **取整**：单日克数四舍五入到整数克；周期总量守恒允许 ±1g；后端按 double 存储防漂移。

### 1.4 食物库与饮食记录

- 一期内置 **200 条** 常见食物（**10 大分类**，F001–F200，《中国食物成分表》第 6 版，每 100g 可食部口径；数据字典见 `docsFile/projectFile/04-食物库数据字典.md`），内置食物库对用户**只读**；用户仅能操作自己的自定义食物。
- 自定义食物：名称同一用户下唯一；宏量校验（蛋白×4 + 脂肪×9 + 碳水×4 ≈ 热量，±10% 误差）；被历史记录引用后**软删 / 停用**而非物理删除（保证历史记录完整）。
- 实际摄入 = 每 100g 营养值 ×（份量 ÷ 100）；支持 g / 个 / 碗 / 勺等单位换算。
- 当日累计实时更新；超标判定：单项超标 / 总热量超标分别高亮 + 微调建议文案。
- 饮食提醒每日单次；已记录饮食当日不再重复推送。

## 2. 监管 / 合同限制

- 所有健康计算结果必须附带免责声明（非医疗建议）——**不可移除**。
- 登录前必须勾选《用户协议》《隐私政策》（微信小程序平台合规）。

## 3. 非目标（一期明确不做）

- 食物拍照识别、AI 识物、条形码扫描。
- 运动课程、社区社交、榜单打卡。
- 付费会员、广告、营销体系。
- 自动体重曲线、全自动数据复盘、详细微量元素（钠 / 膳食纤维等）。
- 食物收藏（二期）、云端同步 / 社区共享食物库（二期）、误删 7 天恢复（二期）。

> 任何 Agent / 开发者不得以「顺手」为由实现上述范围外功能（漂移信号，见宪法 §6 门禁）。
