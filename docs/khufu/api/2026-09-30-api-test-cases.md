## 用例明细

1. **get_returnsDefaults**：携带 Bearer Token GET `/reminder` → HTTP 200，`code=200`，返回默认值（masterSwitch=1、08:30/12:00/18:30）。
2. **save_valid_returnsUpdatedSettings**：合法 JSON PUT `/reminder` → HTTP 200，回显新时间 07:15/12:30/19:00。
3. **save_invalidTime_returnsBusinessCode40701**：时间 `25:99` 非法 → HTTP 200 包裹业务码 `code=40701`（BusinessException 经 GlobalExceptionHandler 处理，HTTP 层不抛非 2xx）。
4. **get_withoutToken_returns401**：无 Authorization 头 → HTTP 401。

## Known Issues

1. API 测试强依赖本地真实 Redis（含密码、db1）；Redis 不可用时登录夹具无法取验证码，测试将整体失败。CI 中需先拉起 Redis 服务。
2. `/reminder/subscribe`（订阅授权上报）未覆盖，其依赖真实 Redis 的 setIfPx 幂等键；如需覆盖，建议在同一登录态下补 POST 用例并清理幂等键。
3. API 层尚未覆盖 CyclePlan、Menstrual、Taper532、CustomFood 等控制器端点，可作为后续接口补全项。
