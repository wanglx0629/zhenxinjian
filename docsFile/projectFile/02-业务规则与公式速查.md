## 1. 全局硬规则

| # | 规则 | 说明 |
| -- | ---- | ---- |
| G1 | 核心计算后端为准 | 前端 calculator.ts 仅用于即时展示与离线兜底，账单以服务端计算结果为准 |
| G2 | 目标体重 ≤ 当前体重 | 减脂场景硬约束（容差 +0.1kg），否则拒绝录入 |
| G3 | 平台期微调仅触发一次 | 触发后标记，禁止连续多轮降碳（防代谢损伤） |
| G4 | 切换减脂模式即重置周期 | 自动终止当前周期、清空当期进度、重启全新周期 |
| G5 | 蛋白不参与经期上浮 | 经期只调碳水和总热量，蛋白脂肪保持基线 |
| G6 | 取整口径 | 单日克数四舍五入（1 位小数）；周期总量分配守恒（±1g）；后端 double 存储防精度漂移 |

## 2. 基础计算（两模式共用）

### 2.1 BMR —— Mifflin-St Jeor 公式

```
女：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 − 161
男：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 + 5
```

### 2.2 TDEE

```
TDEE = BMR × 活动系数
```

| 活动档位 | 系数 |
| ---- | ---- |
| 久坐（几乎不运动） | 1.2 |
| 轻度活动（每周 1-3 次） | 1.375 |
| 中度活动（每周 3-5 次） | 1.55 |
| 高度活动（每周 6-7 次） | 1.725 |

### 2.3 基准热量（目标热量）

```
目标热量 = TDEE − 热量缺口 X
```

- 缺口档位：200（温和，默认）/ 300（标准）/ 400（积极）/ 500，用户自选。
- 隐含下限保护：目标热量不低于 1200（女）/ 1500（男）时提示风险（PRD 安全底线）。

## 3. 532 碳水渐降模式

### 3.1 宏量配比（硬性写死，不可配置）

```
碳水 g = 目标热量 × 50% ÷ 4
蛋白 g = 目标热量 × 30% ÷ 4
脂肪 g = 目标热量 × 20% ÷ 9
```

### 3.2 四阶段推进

| 阶段 | 名称 | 碳水调整 | 热量调整 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 1 | 月初适应期 | — | — | 标准 50/30/20 适应期 |
| 2 | 稳步减脂期（经期适配） | — | — | 按经期阶段自动上浮（见 §5） |
| 3 | 经后高效期 | — | — | 经期结束后按基线稳步推进 |
| 4 | 平台突破期 | **−20g** | **−80 kcal** | 平台期触发（见 §6），蛋白脂肪不变 |

### 3.3 今日目标 = 阶段目标 + 经期叠加

```
今日碳水 = 阶段碳水 + 经期碳水上浮
今日热量 = 阶段热量 + 经期热量上浮
今日蛋白 / 脂肪 = 基线不变
```

## 4. 碳循环模式

### 4.1 三大池（周期总量）

```
碳水池 = 目标体重 × 2.5 × 周期天数(7–14)
脂肪池 = 目标体重 × 脂肪系数(默认 0.8，可切 1.0) × 周期天数
每日蛋白 = 当前体重 × 1.5（周期内固定，不按日浮动）
```

> 注意：碳水池/脂肪池用**目标体重**，蛋白用**当前体重**——这是 PRD 图片公式定稿口径，勿混淆。

### 4.2 日型分配（模板 + 占比）

周期日序模板（7 天一轮，按周期长度循环）：

```
高 → 中 → 低 → 低 → 中 → 高 → 低
```

| 日型 | 碳水占比 | 脂肪占比 | 天数权重 |
| ---- | ---- | ---- | ---- |
| 高碳日 | 50% | 15% | 2.0 |
| 中碳日 | 35% | 35% | 2.2 |
| 低碳日 | 15% | 50% | 2.0 |

单日量计算：

```
高碳日碳水 = 碳水池 × 50% ÷ 2.0
中碳日碳水 = 碳水池 × 35% ÷ 2.2
低碳日碳水 = 碳水池 × 15% ÷ 2.0
（脂肪同理，用脂肪池 × 脂肪占比 ÷ 天数权重）
```

> 周期天数 ≠ 7 时按比例放大（权重和归一），保证总量守恒 ±1g。

### 4.3 碳循环叠加经期

当前日为经期/排卵期时，单日碳水与热量同样上浮（同 §5 数值），蛋白不变；周期池总量不重算。

## 5. 经期周期管理（女性，四阶段）

### 5.1 阶段判定

前置条件：性别 = 女 且 开启经期管理。周期长度 L（21–35，默认 28）、经期天数 D（3–10，默认 5）。

```
dayIdx = (今天 − 经期起始日 的整数天数 mod L) + 1   （未来日期按第 1 天）

dayIdx ≤ D                    → 经期
D < dayIdx ≤ L − 14           → 卵泡期
L − 14 < dayIdx ≤ L − 12      → 排卵期
dayIdx > L − 12               → 黄体期
```

### 5.2 阶段上浮与营养焦点

| 阶段 | 碳水上浮 | 热量上浮 | 营养焦点 |
| ---- | ---- | ---- | ---- |
| 经期 | +15g | +60 kcal | 补铁 · 温补 · 避寒凉（红肉/肝脏/菠菜/红枣） |
| 卵泡期 | — | — | 基线阶段，雌激素上升恢复力佳，正常训练 |
| 排卵期 | +5g | +20 kcal | 控量，补镁锌缓解腹胀 |
| 黄体期 | +10g | +120 kcal | 控盐控水肿，补钙镁，回补热量防暴食 |

> 男性 / 未开启经期管理 → 判定函数返回 null，不叠加。

## 6. 平台期突破

### 6.1 检测规则

```
最近 7 天体重记录的最大值 − 最小值 < 0.3 kg  →  判定平台期
```

- 需 ≥ 2 条近期记录（不足则不判定）。
- 每周一空腹称重为标准采集点。

### 6.2 微调动作（532 阶段 4 / 碳循环同规则）

```
碳水 −20g，总热量 −80 kcal，蛋白脂肪不变；仅触发一次
```

## 7. 食物换算与超标判定

### 7.1 换算口径

```
实摄入 = 每 100g 营养值 × 摄入克数 ÷ 100
能量系数：碳水 4 kcal/g · 蛋白 4 kcal/g · 脂肪 9 kcal/g
```

### 7.2 超标判定

当日累计摄入对比今日目标：任一宏量超出即提示超标，按超出项生成建议（如「碳水超 42g，建议明日主食减半」）；仅提示不拦截记录。
