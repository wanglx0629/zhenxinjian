# home/dashboard Delta（修改现有能力）

## MODIFIED Requirements

### Requirement: 快捷入口与今日餐次

系统 SHALL 提供快捷入口：**「记饮食/去记录」直达食物库 Tab**（`switchTab` 到食物库页），使用户可在食物库直接选食物发起记录、不再多跳一层记录页；「看计划」按当前模式分发——碳循环跳 P07 碳循环计划页，532 跳 P08 四阶段计划卡页。系统 SHALL 展示今日餐次卡：早 / 午 / 晚 / 加餐四餐各自的已记录状态与餐次小计热量（数据来源当日记录接口），点击仍跳记录页对应日期。

#### Scenario: 记饮食直达食物库

- **WHEN** 用户在首页点击「记饮食」（或未建档/空态之外的「去记录」入口）
- **THEN** 通过 switchTab 直接打开食物库 Tab，可立即搜索/选择食物发起添加记录

#### Scenario: 532 模式看计划

- **WHEN** 532 模式用户点击「看计划」
- **THEN** 跳转 P08 四阶段计划卡页

#### Scenario: 碳循环模式看计划

- **WHEN** 碳循环模式用户点击「看计划」
- **THEN** 跳转碳循环计划页

#### Scenario: 餐次摘要反映当日记录

- **WHEN** 当日已记录早餐（400kcal）与午餐（600kcal），晚餐与加餐无记录
- **THEN** 今日餐次卡展示早餐 400kcal、午餐 600kcal，晚餐与加餐为未记录状态
