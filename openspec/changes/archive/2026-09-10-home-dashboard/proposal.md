# Proposal — 首页 Dashboard（P02 今日总览）与「我的」页（P14 个人中心）

## Why

登录/游客、身体档案、食物库、饮食记录四大能力已闭环，但用户打开小程序的第一落点——首页（P02）仍是 Change 1 遗留的占位欢迎页（能力速览 chips），「我的」（P14）也只有账号信息与退出登录。PRD 验收第 4 条要求「对照原型 16 页逐一走查」，P02 的 F09 宏量进度 / F26 超标预警与 P14 的 F05 资料入口 / F10 模式切换入口是小白用户每天必经的主路径，必须补齐。本变更与进行中的 carb-cycle 并行开发（纯前端、复用既有接口，不碰其后端与记录页改动范围）。

## What Changes

**P02 首页今日总览（重写 `pages/home/index.vue` 占位页）**

- 顶部渐变头卡：日期 + 分时段问候；游客剩余时长徽标（F01/F03 既有数据）；今日总热量目标（大字）+ 已摄入 / 剩余 + 热量进度条；当前模式标签（532 / 碳循环·今日日型）
- 今日宏量进度卡（F09/F26）：碳水 / 蛋白 / 脂肪三行进度条（实际 g / 目标 g + 三色口径：80–100% 绿 / <80% 黄 / >100% 红，与 P12 记录页一致）；卡内「换模式」标签跳 P05 模式选择；底部「身体数据摘要 · 修改 ›」跳 P03（F05）
- 超标预警卡（F26）：任一宏量或总热量超标时展示「已超标 XXg / XXkcal」chips + 微调建议文案（口径复用 diet-record 既有文案表，附「非医疗建议」免责注）
- 快捷入口：记饮食（跳记录 tab）；看计划（按 mode 分发：碳循环 → P07 计划页，532 → P04 代谢结果页）
- 今日餐次卡：当日早 / 午 / 晚 / 加餐四餐摄入状态摘要（数据来源 `GET /api/diet/records`），点击跳 P12 记录页
- 页面三态：加载骨架 / 空态（未建档 → 引导 P03 录入档案；已建档无记录 → 引导记第一餐）/ 错误重试；页底健康免责声明（不可移除）

**P14 我的（增强 `pages/mine/index.vue`）**

- 头部用户卡：头像 / 昵称；游客态展示剩余时长 + 「授权登录」入口（F02），正式用户展示账号信息
- 游客数据迁移提示卡（F03，仅游客可见）：临时缓存 / 登录后自动迁移 / 过期 7 天清空口径说明
- 功能列表：身体数据（副标题档案摘要，跳 P03，F05）；减脂模式（副标题当前模式，跳 P05，F10）；隐私与安全（静态说明）
- 数据留存说明卡（F04/F28）与关于卡（版本 + 计算后置说明）
- 保留既有退出登录（二次确认）

**口径假设（记录在案）**

- 纯前端变更：所需数据全部来自既有接口（`GET /api/diet/summary`、`GET /api/diet/records`、`GET /api/body/profile`、用户信息），后端零改动、无新表、无新依赖
- 「换模式 / 减脂模式」入口目标页 `pages/mode/select`（P05）与「看计划」碳循环目标 `pages/cycle/plan`（P07）由并行中的 carb-cycle 变更交付；本变更只做按 mode 的跳转分发，不实现目标页
- 碳循环无进行中周期时，首页按 summary 空态口径（`recorded=false` 同构）引导创建周期（跳 P06，carb-cycle 交付）
- 范围外（归后续变更）：提醒设置入口（P13）与首页提醒状态卡 → 提醒 change；记体重入口与 532 月度计划页（P08/P09）→ 532 推进 change；身体数据历史版本追溯（F08）→ 待 PRD 明确后单独立项

## Capabilities

### New Capabilities

- `home/dashboard`: 首页今日总览——热量头卡（目标 / 已摄入 / 剩余 / 进度条 / 模式标签）、三宏三色进度（F09）、超标预警与微调建议（F26）、快捷入口与今日餐次摘要、未建档与无记录空态、加载 / 错误态、游客剩余时长展示
- `mine/center`: 我的个人中心——用户信息卡（游客 / 正式双态）、游客迁移提示（F03）、身体数据入口（F05）与档案摘要、减脂模式入口（F10）与当前模式展示、数据留存说明（F04/F28）、退出登录

### Modified Capabilities

（无——首页与我的页均为既有占位页的首个完整实现，无既有 spec 需求被修改；`diet/progress` 的 summary 接口与三色口径仅被消费，不改其行为）

## Impact

- **代码**：uniapp 重写 `pages/home/index.vue`、增强 `pages/mine/index.vue`；新增首页组装逻辑（复用既有 `store/diet.ts`、`store/body.ts`、`store/user.ts` 与 `api/diet.ts`、`api/body.ts`）；`config/constants.ts` 视情况补充模式 / 餐次展示字典（与 carb-cycle 同文件改动需汇合时注意冲突）；可能抽取三宏进度条 / 超标建议卡为共享组件供 P02 与 P12 复用
- **后端**：无改动
- **数据**：无新表、无迁移脚本
- **口径真源**：MVP v1 §首页总览 / §我的、高保真原型 P02 / P14、PRD 验收第 4 条；三色进度与超标建议文案口径以已归档 diet-record 变更为准
- **跨 change 依赖**：carb-cycle（进行中）交付 `pages/mode/select`、`pages/cycle/setting`、`pages/cycle/plan` 与 summary 的 mode / 日型分发；本变更跳转分发以其路由为准，联调验收需在 carb-cycle 合并后走查
