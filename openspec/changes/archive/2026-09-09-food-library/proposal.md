# Change 4 — 食物库（内置 200 条 + 搜索筛选 + 自定义食物）

## Why

登录/游客（Change 1）与身体档案/核心计算（Change 2）已就绪，但「记得快」能力完全缺失：小程序食物库页仍是占位页，后端无 `foods` 表、无食物接口，200 条《中国食物成分表》数据仅存在于小程序离线文件 `src/data/foods.ts`。没有食物库，后续饮食记录（Change 5）无从选食物。本变更建立后端权威食物库并完成 200 条内置数据导入，打通「搜食物 → 看详情」闭环，兑现 MVP v1 Phase 2 的食物库部分。

## What Changes

**后端（zhenxinjian-backend）**

- 新建 `foods` 表（迁移脚本走仓库根 `sql/changeN` 手工编号风格）：内置/自定义食物同表，`source`（1 内置 2 自定义）+ 自定义食物归属 `user_id`，必备 `delete_flag`（`@TableLogic`）+ `status`；自定义食物名称按用户活跃唯一（生成列活跃唯一约束，同 `user_body` 做法）；内置食物全局只读
- 内置数据导入：`foods_200.json`（PRD 索引指定的后端导入唯一真源）拷贝进后端 resources，幂等初始化器首次启动导入 200 条（已有数据则跳过），口径遵守数据字典（每 100g 可食部、干重不泡发、生熟分列）
- 食物库接口：搜索（关键字模糊匹配名称+别名）/ 分类筛选 / 分页、分类列表、热门食物、自定义食物增/改/删（软删）
- 后端兜底校验：自定义食物宏量区间合法 + 能量守恒（碳水×4 + 蛋白×4 + 脂肪×9 ≈ kcal，±10%，不变量 I11）；数据归属校验（仅能改删自己的自定义食物，不变量 I9）
- `ExceptionConstant` 新增食物库文案，业务错误码启用 404xx 段位（401xx 微信 / 402xx 游客 / 403xx 身体已占用）
- 新建字典枚举：`FoodSourceEnum`（1 内置 2 自定义）、`FoodCategoryEnum`（01–10 十大分类）

**小程序（zhenxinjian-uniapp）**

- P10 食物库页（替换 `pages/food/index.vue` 占位）：搜索框（防抖 300ms）+ 分类筛选 + 历史搜索（本地存储，上限 10 条）+ 热门搜索（内置静态清单）+ 结果列表分页；后端失败时降级 `src/data/foods.ts` 离线兜底
- 食物详情弹层/页：每 100g 营养值 + 默认份量（serving）克数输入，实时换算碳水/蛋白/脂肪/热量（值 × 克数 ÷ 100）；本期仅落「查看与试算」，写入饮食记录入口留待 Change 5
- 自定义食物录入/编辑页：名称 + 每 100g 三宏 + 能量，前端先做区间与 ±10% 守恒校验，提交以后端为准；「我的自定义」列表可编辑/删除（删除即软删，二次确认）

**口径假设（记录在案）**

- 份量录入以**克数**为准（默认值取每条 `serving`），PRD 提到的「个/碗/勺」单位换算因 200 条数据无权威单位换算数据（数据字典仅交付 serving 克数）本期不做，待 PM 补充单位数据后另立变更
- 热门搜索为内置静态清单（饮食记录表未建，无统计口径），后续 Change 5 后可升级为按记录次数统计

## Capabilities

### New Capabilities

- `food/library`: 内置食物库——200 条权威数据导入与留存，名称+别名模糊搜索（防抖）、分类筛选、分页、热门、详情与份量试算；内置食物全局只读；后端失败时小程序离线兜底
- `food/custom`: 自定义食物——新增/编辑/软删，名称按用户活跃唯一，宏量区间 + 能量守恒 ±10% 双重校验（后端兜底），数据归属隔离（仅能操作自己的），删除一律软删不物理删

### Modified Capabilities

（无——`auth/guest-mode` 的游客数据迁移不覆盖食物：内置食物全局共享无需迁移，自定义食物随游客身份产生即归属游客账号，登录迁移待饮食记录（Change 5）落地后统一评估，本期游客可正常使用食物库）

- **依赖**：无新增后端 maven / 前端 npm 依赖

- **数据**：`sql/` 新增 `foods` 表迁移脚本；`users` / `user_body` 表不变
- **口径真源**：`doscFile/projectFile/04-食物库数据字典.md`；导入源 `MRD-PRD/foods_200.json（开发导入用）.json`（已与 xlsx、`foods.ts` 全量对拍一致）
- **前置**：依赖 Change 1/2 已归档；Change 5 饮食记录（`diet_records` 快照引用食物）依赖本变更的食物表与接口
