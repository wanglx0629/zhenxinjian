# Proposal — 532 碳水渐降推进（P08 月度计划 + P09 体重记录与调碳 + 经期管理）

## Why

MVP 四大能力中「算得准」只落地了一半：核心计算（BMR/TDEE/532 基准占比）与碳循环模式均已交付，但 532 模式目前仅有「档案目标快照」这一层——`diet/summary` 对 532 的目标值仍直接取 `user_body.targetCarb/targetProtein/targetFat/targetKcal`，四阶段推进、经期四阶段上浮、周一体重记录与平台期调碳（P08/P09）全部缺失。不变量 I5（调碳兜底）与 PRD 验收第 2 条「周期逻辑、体重调碳逻辑 100% 闭环生效」因此无法达标。本变更补齐 532 的「能坚持」闭环：体重记录 → 平台判定 → 下调/恢复 → 今日目标动态叠加，并落地跨模式通用的经期管理（速查 §5，也供碳循环叠加经期复用）。

## What Changes

- **经期管理（跨模式通用）**：新建 `user_menstrual` 表（每用户一条活跃：是否开启 + 末次月经起始日 + 周期长度 21–35 默认 28 + 经期天数 3–10 默认 5）；`GET/PUT /api/menstrual` 设置接口；后端四阶段判定引擎（dayIdx = (今天−起始日) mod L + 1 → 经期/卵泡/排卵/黄体）与经期上浮值（经期 +15g 碳/+60kcal、排卵 +5g/+20kcal、黄体 +10g/+120kcal、卵泡基线；男性/未开启返回空态）。**口径**：经期上浮为跨模式基础能力，532 与碳循环都叠加，蛋白脂肪不变（G5）
- **体重记录（P09 F19）**：新建 `weight_record` 表（user_id + 记录日期 + 体重 kg + 体重来源/备注，数据永久留存）；`GET/PUT/DELETE /api/weight` 增删改查（同日期幂等覆盖）；每周一空腹称重为标准采集点（仅引导，不强制校验）；**单位 kg/斤双单位**（后端统一存 kg，前端按斤换算展示与录入，1 斤 = 0.5kg）
- **平台期判定与调碳（P09 F20/F21/F22）**：后端平台判定引擎 = 最近 7 天体重记录（≥2 条）最大值 − 最小值 < 0.3kg；触发后今日目标碳水 −20g、热量 −80kcal、蛋白脂肪不变；新建 `adjust_log` 调碳日志表（下调/恢复动作留痕，追溯 F21/F22）；**下调状态持久化**：触发后持续生效，体重恢复下降（当前体重较触发参考体重下降 ≥0.3kg）则解除下调回到基线；禁止连续多轮下调（G3/I5）
- **532 四阶段计划卡（P08）**：`GET /api/taper-532/plan` 返回四阶段计划卡（阶段 1/2/3 碳热调整为 0，阶段 4 为平台触发式 −20/−80）；今日 532 目标 = 档案基线 + 平台下调（若有）+ 经期上浮（若叠加）
- **今日目标分发改造**：`diet/summary` 对 532 模式的目标值从「直接取档案快照」改为「532 推进目标」（基线 + 平台下调 + 经期上浮）；碳循环模式叠加经期上浮（蛋白固定不变）
- **游客迁移补齐**：`Taper532Migrator` 迁移游客经期设置/体重记录/调碳日志归属（幂等 UPDATE），过期清理逻辑删除
- **错误码**：启用 408xx 段位（经期设置非法 / 体重记录非法 / 平台判定相关）

**范围外（后续变更）**：自动体重曲线与全自动复盘（宪法 Never 明确一期不做）；碳循环周期内平台调碳回改已固化日目标（碳循环日目标创建时固化，不回改）；加餐/532 之外的提醒扩展。

## Capabilities

### New Capabilities

- `body/menstrual`: 经期周期管理——开启/关闭与末次月经起始日/周期长度/经期天数设置、四阶段判定（经期/卵泡/排卵/黄体）、经期上浮值（+15/+60、+5/+20、+10/+120、基线），男性/未开启空态；跨模式通用（532 与碳循环均叠加）
- `body/weight`: 体重记录——按日增删改查（同日期幂等覆盖，kg/斤双单位）、数据永久留存；平台期判定（近 7 天 ≥2 条 波动 <0.3kg）；平台下调触发（碳水−20/热量−80）与恢复解除（较触发参考下降 ≥0.3 无条件窗口）；调碳日志留痕
- `body/taper-532`: 532 碳水渐降推进——四阶段计划卡查询、今日 532 目标公式化（基线 + 平台下调 + 经期叠加，蛋白脂肪不变）

### Modified Capabilities

- `diet/progress`: 当日累计的 532 目标来源从「档案目标快照」改为「532 推进目标」（基线 + 平台下调 + 经期上浮）；碳循环模式目标增加经期上浮叠加
- `mine/center`: 功能列表新增「体重记录」与「月经周期」入口（跳 P09 / 经期设置页），其余需求不变
- `home/dashboard`: 头卡新增经期阶段徽标（仅女性且已开启经期管理时展示当前阶段）；看计划入口 532 跳转目标调整为 P08 四阶段计划页
