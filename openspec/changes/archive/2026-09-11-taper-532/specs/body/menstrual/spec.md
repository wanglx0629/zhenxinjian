## Purpose

为用户（女性，跨模式通用）提供经期周期管理：开启/关闭与末次月经起始日/周期长度/经期天数设置，四阶段判定与经期上浮（蛋白脂肪不变），供 532 推进与碳循环模式叠加。

## ADDED Requirements

### Requirement: 经期设置保存与查询

系统 SHALL 提供经期管理设置（每用户一条活跃记录）：是否开启（默认关）、末次月经起始日、周期长度 L（21–35，默认 28）、经期天数 D（3–10，默认 5）。开启时 MUST 已填写末次月经起始日且不得为未来日期；L 或 D 越界 MUST 拒绝并返回 408xx。男性用户 MUST 返回「不适用」标记而非报错。

#### Scenario: 女性保存有效设置

- **WHEN** 女性用户保存「开启、起始日 7 天前、L=28、D=5」
- **THEN** 设置持久化，再次查询返回相同值

#### Scenario: 越界拒绝

- **WHEN** 用户保存 L=20 或 D=11，或开启但起始日为空/未来日期
- **THEN** 被拒绝，返回 40801「经期设置非法」，原设置不变

#### Scenario: 男性不适用

- **WHEN** 男性用户查询经期设置
- **THEN** 返回「不适用」标记，界面隐藏经期相关内容，不报错

### Requirement: 经期四阶段判定

系统 SHALL 按 dayIdx = (今天 − 末次月经起始日的整数天数 mod L) + 1（未来起始日按第 1 天）判定阶段：dayIdx ≤ D → 经期；D < dayIdx ≤ L−14 → 卵泡期；L−14 < dayIdx ≤ L−12 → 排卵期；dayIdx > L−12 → 黄体期。未开启或非女性 MUST 判定为空态。

#### Scenario: 经期阶段

- **WHEN** 女性起始日 3 天前、L=28、D=5（dayIdx=4）
- **THEN** 阶段为经期

#### Scenario: 卵泡期与排卵期

- **WHEN** 女性起始日 7 天前、L=28、D=5（dayIdx=8）为卵泡期；起始日 21 天前（dayIdx=22）为排卵期
- **THEN** 分别判定为卵泡期、排卵期

### Requirement: 经期上浮值

系统 SHALL 对经期各阶段叠加碳水与热量上浮，蛋白脂肪不变：经期 +15g 碳水/+60kcal、卵泡 +0/+0、排卵 +5g/+20kcal、黄体 +10g/+120kcal。上浮值为跨模式基础能力，532 推进与碳循环模式 MUST 均叠加。

#### Scenario: 经期上浮

- **WHEN** 用户处于经期阶段
- **THEN** 碳水上浮 +15g、热量上浮 +60kcal、蛋白脂肪上浮 0

#### Scenario: 空态无上浮

- **WHEN** 未开启经期管理或非女性
- **THEN** 经期判定为空态，上浮值均为 0
