# 双端页面级旧色迁移 — Design

## 1. 替换映射（与 V2.0 §8.1 一致）

| 旧（V1.1） | 新（V2.0） | 语义 |
| ---- | ---- | ---- |
| `#0D9488` | `#00AC7C`（或 `$zhenxinjian-primary` / `var(--zhenxinjian-primary)`） | 品牌主色 |
| `#14B8A6` | `#33BD96` | 渐变副色 |
| `#5EEAD4` | `#80D6BE` | 高亮 |
| `#0F766E` | `#008A63` | 深色态 |
| `#99F6E4` | `#B3E7D8` | 浅阶 |
| `#CCFBF1` | `#E3EFE9` | 描边/浅底 |
| `#F0FDFA` | `#F4F8F6` | 底色 |
| `#134E4A` | `#10312B` | 标题墨色 |
| `#22C55E` | `#00AC7C` | 充足 |
| `#F59E0B` | `#FFB020` | 不足 |

| `#EA580C` | `#E69A00` | CTA 按压 |

`rgba(13,148,136,x)` → `rgba(0,172,124,x)`；`rgba(249,115,22,x)` → `rgba(255,176,32,x)`（阴影按 §8.4 统一值优先）。

## 2. 规则

- `<style lang="scss">` 内：色值若与 token 同义，优先改写为 `$zhenxinjian-*`；仅当色值是装饰性独特色时直接换新值
- 后台 `<style>`（非 scss）：CSS 环境用 `var(--zhenxinjian-*)`；模板/JS 中的字符串色值直接换新值
- SVG 描边/填充属性中的色值：直接换新值（内联属性不解析变量）
- 保持现有类名、结构、文案不变；不做组件重构
- `constants.ts` 等 TS 常量：直接换新值（不能引 SCSS 变量）

## 3. 验收

- 双端 `src` 下 grep 全部 V1.1 旧色值（含大小写）零残留
- 双端可构建（依赖可用时跑 build；不可用时以 grep + 人工走查为准并注明）
