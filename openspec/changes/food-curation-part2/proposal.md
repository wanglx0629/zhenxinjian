# 食物库用户共建审核 + 原型 PART2 交互调整 — Proposal

| 项目 | 内容 |
| ---- | ---- |
| Change ID | food-curation-part2 |
| 类型 | feature（食物库共建子系统 + 小程序 PART2 交互） |
| 涉及端 | `apps/zhenxinjian-backend`、`apps/zhenxinjian-front`（PC 管理后台）、`apps/zhenxinjian-uniapp`（小程序） |
| 依据 | 《原型沟通.docx》PART1（260904）+ PART2（260914）；两者冲突以 PART2 为准。本批落地 **A + C + D**，B 批（协议勾选/经期文案/建档拦截/年龄14-60/P12时间/P13时间窗与超标推送等）另开变更 |

## Why

- **C 食物库长期依赖管理员单人更新，200 条基础数据太少且增长停滞**：开放用户共建，经 AI 校验 + 管理员终审后上架，才能让食物库持续扩充、形成"大家共建"。同时必须在数据模型和后台清楚区分「基础食物（含官方导入）」与「用户共建食物」，方便管理员做特殊操作（审核/修正/下架）。
- **A 原型沟通 PART2 已确认的交互问题**：「记饮食」入口绕、食物库缺取消、532/碳循环计划页操作不符合最新原型（P08/P07/P16-F15），需要按 PART2 快速修正。
- **D 现有 200 条覆盖不足**：引入合法开放数据扩充食物库，给用户记录饮食和共建提供更全的基础数据。

## What Changes

### A. 小程序 PART2 交互调整（纯前端）

- 首页「记饮食/去记录」由跳转记录 Tab 改为 `switchTab` **直达食物库**。
- 食物库搜索栏新增「取消」按钮：清空搜索输入框、失焦收键盘。
- 532 推进计划页新增「**生成周期计划**」按钮（P08/PART2）：无计划时引导生成；已有计划则展示当前计划（不做文档搁置的体重记录/调碳日志/续期入口）。
- 碳循环计划页：新增自定义「**返回**」；「终止当前周期」文案与交互改为「**提前结束/切换模式**」，二次确认弹窗按原型 F15/P16 重做——展示当前周期日期、第 N/7 天、已消耗碳水（g/周期总量）、「确认切换并重启周期 / 取消，继续当前周期」。
- 体重历史记录：现版本已正确渲染（无 PART2 截图中的 `[object Object]`），**维持现状不改动**。
- 微信头像昵称授权：change 已实现，本批不再改动。

### C. 用户共建食物库（三端联动）

- 用户端自定义食物表单在现有 CRUD 上补齐：**图片上传**、**单位**（份/个/杯/包等）、**数量克数**、**千焦/千卡单位下拉二选一**（另一单位按 4.184 自动联动）、蛋白/脂肪/碳水；无图时按分类回退占位展示（不新增美术资源）。
- 引入审核状态机：用户提交后为「待审核（私有·本人立即可用）」，经 **AI 提交即校验打标**（pass/suspect/reject + 建议）与**管理员终审**，通过则转为「已通过（公共·全员可见，原作者只读）」；驳回则保留私有可用并附驳回原因，作者修改后可重新提交。
- 全程操作留痕到新增的 `food_audit_log`（提交/AI结论/通过/驳回/重提，含前后快照）。
- 管理后台食物库页新增「数据来源（全部/基础食物/用户共建）+ 审核状态（待审核/已通过/已驳回）+ 分类 + 名称」筛选，待审行展示 AI 结论并支持【通过】【驳回（填原因）】【修正后通过】。
- 扩展现有智谱 AI 链路支持**纯文本营养合理性校验**（当前 `AiChatClient` 仅支持图片多模态），新增文本模型配置项；AI 不可用时降级为「未校验」进入人工，不阻塞用户投稿。

### D. 基础食物数据扩充（TFDA 开放数据）

- 实施阶段获取台湾卫福部食药署 **TFDA《食品營養成分資料庫》**官方数据（约 2000 项、A–R 共 18 大类、每 100g 含热量/蛋白/脂肪/碳水），通过可复跑脚本转换导入：OpenCC 繁转简、名称归一与现有 200 条去重、18 大类映射现有分类、kcal/kJ/三大营养素落库，标记为 `source=1` 基础食物、批次来源 TFDA；**不爬 ostsc.cn**（其条款禁止抓取）。
- TFDA 无图，导入食物统一按分类占位展示；图片后续由用户共建上传补充。
- 合规署名：小程序「关于/数据来源」与后台标注「数据来源：卫生福利部食品药物管理署（OGL）」。

## Capabilities

### New Capabilities

- `food/curation` — 用户共建食物的投稿、AI 校验打标、审核状态机、可见性（私有→公共）、操作留痕。
- `food/import` — TFDA 开放数据的获取、繁简转换、去重、分类映射、批次导入与署名合规。

### Modified Capabilities

- `food/custom` — 自定义食物表单新增图片/单位/千焦千卡字段与提交校验；列表/详情展示审核状态与占位图；转公共后原作者只读。
- `admin/food` — 后台食物库页新增来源/审核状态筛选与【通过/驳回/修正后通过】审核操作，清晰区分基础食物与用户共建食物。
- `body/taper-532` — 532 计划页新增「生成周期计划」入口（仅入口与必要的生成动作，不引入搁置的体重/调碳/续期）。
- `body/cycle-plan` — 碳循环计划页新增「返回」，「终止」改为「提前结束/切换模式」并按 F15 展示周期明细的二次确认。
- `home/dashboard` — 首页「记饮食/去记录」入口改为直达食物库。
- `food/library` — 食物库搜索栏新增「取消」按钮；列表支持共建食物（含占位图与状态标识）。

## Impact

- **后端**：`foods` 表加列（`audit_status`/`kj`/`unit`/`image`/`audit_remark`/AI 字段/`submit_time`/数据批次）+ 新增 `food_audit_log` 表；新增 `sql/change14_*.sql`；新增共建审核相关 Controller/Service/DTO/VO、字典枚举（`FoodAuditStatusEnum`）；扩展 `AiChatClient` 为文本+图片；新增 TFDA 导入脚本（沿用现有 data-import 体系）；新增配置键（AI 文本模型）。
- **管理后台**：`view/foods/index.vue` 改造 + `api/adminFood.ts` 新增审核接口；新增审核状态/来源标签与筛选。
- **小程序**：`pages/home`、`pages/food/*`、`pages/taper/plan.vue`、`pages/cycle/plan.vue`、`components/ModeSwitchConfirm.vue`；图片上传复用 `/file/upload`；`api/food.ts` 扩展。
- **合规**：OGL 署名；TFDA 数据获取须走官方渠道，禁止抓取 ostsc.cn。
- **不在本批**：B 批（P01 协议勾选、P02 经期文案与建档拦截、P03 年龄14-60、P12 记录时间字段、P13 时间窗/超标推送、碳循环 5 步计算口径重算）；OFF/USDA 等其它数据源；食物实拍图抓取。
